## 真实 Windows 服务器

在 Windows / Claude Desktop 4.29.0 的专用测试聊天及本次创建的测试聊天验证。

最终 Agent SHA256：a243633548afebbe910f54e5fe05418b25cacca956e6b2c2a917a3ffb3029e10。

服务器回报的运行文件哈希与交付构建一致。通过流程：

1. 从旧测试聊天打开空白新聊天，隔离保存旧本地草稿。
2. 首条消息建立正式编号，客户端核对结束并清除对应已提交原稿。
3. 读取到唯一的本次用户消息及真实 Claude 回复。
4. 新建前、回复后服务器均回报零活动 RDP 会话。
5. 切回旧聊天恢复草稿，再从最近列表返回新聊天，正式编号与消息无重复。
6. 另一轮在传输适配层故意丢弃一次已收到的发送回执；客户端保留待核对原稿，重建配对连接后按原操作核对成功，没有再次调用发送。

回执丢失为受控注入，不是运营商网络故障。首轮开发构建另有 RDP 在线流程检查，最终验收以哈希一致的无 RDP 流程为准。
