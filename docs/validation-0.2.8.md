# ServerLink 0.2.8 更新与检查记录

日期：2026-10-28。

## 变更

- 本地 Client、服务器 Host 和 Agent 均重新编译；界面、程序集及文件版本统一为 0.2.8 / 0.2.8.0。
- 三个程序的启动入口接入共用作者弹窗，内容严格为“作者QQ：230154231”，每次启动显示，没有“不再显示”开关。
- Host 托盘守护启动、从托盘打开管理窗口，以及 Agent 后台启动均接入弹窗。后台弹窗独立于隐藏的主窗口，不阻塞监听或守护循环；关闭弹窗不退出后台。
- 手动再次打开已运行的 Agent 时，新进程仅显示作者信息，保留原实例；重复后台实例仍沿用现有实例。
- 保留 0.2.7 单行尾部空白处理、原始草稿保护、旧版待核对记录兼容及不自动重发的逻辑。
- 构建脚本加入共享的 `ApplicationInfo.cs`，源码包可重新构建三个程序。

## 已完成检查

1. 三份发布 EXE 编译成功，版本为 0.2.8.0，均含有准确的作者文字。
2. 26 项客户端内存模拟回归全部通过，包括单行末尾空行、正文格式、草稿保护及重连确认。
3. 6 项纯解析/传输检查通过。
4. 使用独立的共享弹窗预览检查显示内容及布局，确认有准确文字和“确定”按钮。
5. 预览检查确认弹窗未关闭时后台消息循环仍运行；关闭后消息循环继续运行。此检查不启动 Agent、不连接 Claude、不读取配对或草稿。
6. 核对三个生产程序及守护的弹窗接入位置，按明确文件清单打包并校验 SHA256。
