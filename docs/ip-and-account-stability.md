# IP 与账号稳定性：这个项目解决什么

## 适用场景

你可能经常更换本地电脑、网络或出口 IP，或担心某个本地网络环境影响账号使用，希望 Claude 始终运行在自有服务器上，而本地只保留一个操作窗口。

ServerLink 的做法是固定执行位置：Claude Desktop 在服务器运行，本地客户端只连接该服务器的 Agent。切换本地设备时，不必在每台本地电脑重新运行 Claude。本项目不会配置代理，也不会替你购买、挑选、验证或切换服务器出口 IP。

## 关于“特定 IP 导致封号”

仅凭账号封禁和当时使用的 IP，不能在本项目中确认封禁原因。本仓库没有服务商风控日志，也没有识别“安全 IP”或“已标记 IP”的功能，不能承诺换到服务器或固定 IP 就避免封号。

因此，本项目描述的是**统一运行环境与服务器网络出口的操作工具**，不是防封号服务。它不会隐藏所有远程操作特征，不修改服务商对账号的判断，也不提供账号解封、地区身份伪装或绕过访问限制的功能。请遵守服务商适用的账号、地区和使用规定。

## 常见误解

| 说法 | 实际情况 |
| --- | --- |
| 有服务器就一定不会封号 | 无法保证，工具不掌握账号处理原因。 |
| 软件会提供固定、可信的 IP | 不会，实际出口由自己的服务器网络决定。 |
| 服务器看不到本地连接 | 不会作这种保证，服务器仍可记录到桥接连接。 |
| 不开远程桌面等于不需要服务器登录 | 仍需保持正确的 Windows 用户会话、Claude 和桥接运行。 |
| 能控制桌面聊天就等于支持全部 Code 任务 | 当前项目尚未完整支持项目与 Code 任务接管。 |
