# 常见问题

## 无法连接

确认服务器 Agent 已启动、地址和 TCP 39443 可达，且使用正确配对信息。核对云防火墙与 Windows 防火墙是否允许自己的客户端。配对密钥或证书变化时需要重新配对，不要关闭证书校验。

## 发送一直“核对中”

先查看原会话是否已有消息。重连原服务器、等待读取和核对，不要重复提交。桥接回执不代表原应用一定已收发成功；网络中断、界面变化、文本显示差异都可能需要进一步核对。

0.2.7 起，一行文字后全部为空白行时会在发送前忽略尾部空白。报告此类问题时，请说明按了一次还是两次 Enter、正文是否多行、是否有代码围栏；用虚构内容复现。

## 提示服务器有草稿

先保存本地文字，核对服务器原应用草稿。可使用“取回服务器草稿”保存并清理当前草稿；两边文字不同时程序会拒绝覆盖。取回草稿不会发送，也不能证明之前的消息是否成功。

## 不开远程桌面就不能发送

确认曾通过 Host 完成后台运行配置，并保持服务器 Claude、Agent 和登录用户会话。手动退出 Claude 后普通重新打开可能没有沿用后台参数，应保存草稿、等待回复结束，再通过 Host 配置。每台服务器都应测试断开远程桌面后的真实收发。

## 升级或启动出现系统提示

从自己的可信构建或本项目发布包取得程序，核对 SHA256。系统要求人工确认时先检查程序来源；无需为了本工具关闭系统防护。

## 软件支持全部 Claude 功能吗

目前是聊天试用版，具体未完成项见路线图。不要把“能显示当前聊天”和“完整接管全部项目、历史与 Code 任务”等同。
