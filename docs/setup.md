# ServerLink 0.2.8 使用说明

本地客户端、服务器 Host 管理程序和 Agent 桥接程序已统一重新编译为 0.2.8，保留单行末尾空行的优化。

## 启动弹窗

每次启动本地客户端、服务器管理程序或桥接程序，都会显示作者信息：

**作者QQ：230154231**

点击“确定”关闭即可。弹窗不会阻塞服务器后台连接或守护。服务器在没有远程桌面连接时，弹窗位于服务器自己的用户会话中，不会传到本地；本地客户端会显示自己的弹窗。

## 已有环境怎么更新

1. 保存本地未发送的文字，退出旧客户端。
2. 在本地解压本地端或完整包，打开“本地客户端”里的 `ServerLink.Client.exe`，确认版本为 0.2.8，关闭作者弹窗后使用已保存的配对重连。
3. 在服务器新建一个固定文件夹，将新版 `ServerLink.Host.exe` 和 `ServerLink.Agent.exe` 放在一起。不要覆盖正在运行的旧 EXE。
4. 如果旧版守护正在运行，先从服务器托盘退出旧守护。打开新文件夹里的 Host，点击“启动新版桥接”，由它停止旧桥接并启动同目录的新 Agent。作者弹窗可以直接关闭。
5. 同一个 Windows 用户的数据目录不变，已有配对通常可继续使用。若连接断开，本地点击“切换 / 重连”。
6. 用一行文字加末尾空行测试收发，再断开维护远程桌面重新测试。日常无需打开远程桌面。

此次交付的是打包文件，尚未替换你服务器上正在运行的旧版本。需要服务端也显示作者信息时，请一并更新 Host 和 Agent。

## 首次部署

两端需要 64 位 Windows 和 .NET Framework 4.8。每位使用者连接自己的 Windows 服务器和 Claude 环境，本地不需要安装 Claude。

1. 在服务器登录安装 Claude 的 Windows 用户，打开 Claude 并完成正常登录。
2. 将服务器程序放在固定目录，打开 Host，填写自己的公网地址或域名。
3. 保存草稿并等待回复结束后，点击“配置后台运行并重启 Claude”，再点击“启动新版桥接”。配置会重启 Claude。
4. 如需要登录 Windows 后自动运行守护，可勾选对应选项后完成后台配置。
5. 允许客户端访问服务器 TCP 39443 端口；程序不会自动修改云防火墙或 Windows 防火墙。
6. 在 Host 复制客户端配对信息，在本地客户端中粘贴连接。配对信息含访问密钥，只交给授权使用者。
7. 完成收发检查后断开远程桌面，再做一次收发验证。不同服务器和 Claude 版本需要分别验证。

## 空行与草稿

Enter 换行，Ctrl+Enter 发送。只有一行正文且后面全是空白行时，发送前会忽略这些末尾空白行；多行正文、中间空行、开头空行及代码内部格式继续保留。

发送确认前保留原始草稿，失败或中断时不自动重发。发送过程中修改过的新草稿不会被上一条消息的确认清掉。旧消息仍“核对中”时，应先重连原会话核对，避免重复发送。

本地数据位于 `%LOCALAPPDATA%\ServerLinkClient`，服务器数据位于 `%LOCALAPPDATA%\ServerLinkAgent`，由当前 Windows 用户加密。请勿把这些目录随程序分发。

服务器需保持 Claude、桥接及已登录的用户会话运行，断开远程桌面即可，不要注销用户。如果退出 Claude 后自行重新打开，可能需要在 Host 中重新完成后台运行配置。
